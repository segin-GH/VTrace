# VTrace

**Trace your commits in prod**

VTrace is a lightweight Git hook–based tool that automatically updates a version file with metadata like the latest commit SHA, Git tag, branch name, and timestamp. Perfect for tracking exactly what code is running — especially in production environments.


### Why Vtrace
 — because “what SHA is this?” shouldn't be your first question in production.

## Features

- Auto-updates a `version.txt` (or any file that you want)
- Git hook integration (pre-commit, post-commit, or custom)
- Tracks commit SHA, tag, timestamp, and branch
- Minimal and dependency-free
- Works with any language or framework
